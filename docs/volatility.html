📊 區間波動率是怎麼算出來的？

1. 資料來源

不是每檔股票各抓一個檔案，而是抓區間內「每一天」的全市場快照：
data/{market}/daily_price/{date}.json，每個檔案包含當天上市或上櫃「所有股票」的收盤價等資料。 這樣抓取次數等於「選定區間的交易日數」，跟股票檔數無關，比逐檔股票抓歷史檔快很多。

2. 決定要抓哪些日期

先讀取 data/manifest.json 取得每個市場實際有資料的日期清單，再用你在 calendar 選的起訖日期去過濾這份清單。 所以就算選到假日或非交易日，也只是自然被濾掉，不需要額外校正。

3. 聚合每檔股票的收盤價序列

把區間內每天的快照抓回來後，依「市場_股票代號」分組，把每天的收盤價依序放進同一檔股票的陣列裡。

4. 計算波動率

  • 日報酬率：r = (今日收盤 − 昨日收盤) / 昨日收盤
  • 日波動率 = 這些日報酬率的標準差
  • 年化波動率 = 日波動率 × √252
  • 期間漲跌 = (區間最後一天收盤 − 第一天收盤) / 第一天收盤
  • 均價 = 收盤價的算術平均

5. 資料完整性過濾

勾選「只計算區間內每個交易日都有成交的股票」時，只保留區間內每一天都有出現的股票；不勾選則放寬到至少 2 天資料即可計算。 這是因為中途下市或長期停牌的股票，只用剩下那一小段資料算出來的標準差會異常偏小，看起來「很穩定」其實只是資料不全造成的假象，勾選這個選項可以避免被誤導。

6. 排序與分頁

所有股票算完後預設依「日波動率」由小到大排序（最穩定的排最前面），點表頭可切換其他欄位排序；分頁只是把結果依你選的每頁筆數切片顯示，不會重新抓資料。
