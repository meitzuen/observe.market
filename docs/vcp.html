📐 什麼是 VCP？
VCP（Volatility Contraction Pattern，波動收縮型態） 是 Mark Minervini 提出的選股法，尋找股價在上升趨勢中，經歷一系列 一次比一次更小的拉回（收縮），同時成交量逐漸萎縮、股價貼近前波高點整理的個股 — 這類股票在突破整理區時，往往伴隨量能放大，成為潛在的強勢股。 本頁使用近期日線資料自動掃描，計算每檔股票的：
  1. 收縮次數：股價高低點間偵測到的拉回次數
  2. 收縮幅度是否遞減：每次拉回是否比前一次更小
  3. 量縮比：近期拉回量能 / 初期拉回量能
  4. 距樞紐點距離：目前股價距離前波高點（潛在壓力/突破點）的百分比
  5. 站上 50 日均線：確認股價維持在中期均線之上
並綜合成 0~100 的型態分數，分數越高代表越貼近典型 VCP 型態，僅供研究參考，不構成投資建議。
