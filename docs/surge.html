起漲日之後，漲到各個門檻各花了幾個交易日

起漲到各門檻的交易日 0
快慢
說明：怎麼算、標記代表什麼
起漲日：以 STOCKS 清單中的 start 日期收盤價為準；沒填 start 的股票，自動取資料期間內收盤價最高那天之前、收盤價最低的一天。天數 = 從起漲日算起的交易日數，以收盤價判斷是否到達，滑鼠移到天數上可看到達標日、收盤價與工作天（週一到週五，國定假日也算）。
股價區間：依最新收盤價分組，每格是該組到達門檻的中位數交易日（已排除疑似除權息的數字），下方小字是達標檔數／總檔數。
漲點門檻：起漲價 1000 元以上看漲 250／500／750／1000／1250 元，100 元以上看漲 100／200／300／400／500 元，低於 100 元看漲 25／50／75／100／125 元，格子上方小字是該格的門檻。
黃色 !（疑似除權息）：價格未還原權息，起漲日之後單日變動超過 ±10.5% 就標記，滑鼠移上去看日期與價格；落在異常日之後的天數會變淡並加底線，表示可能失真。
灰色 !（資料起點）：起漲日落在資料第一天，實際起漲可能更早，天數會偏短。未達：沒有漲到該門檻。
